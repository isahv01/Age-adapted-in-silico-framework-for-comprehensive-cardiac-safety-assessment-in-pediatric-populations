Pediatric In Silico Cardiac Safety - Age-Specific Populations of Ventricular Action Potential Models

This repository contains the simulation, calibration, and analysis scripts used to build age-specific populations of human ventricular cellular action potential (AP) models for pediatric cardiac drug safety assessment. The framework is based on the O'Hara-Rudy formulation and covers four age groups: infant (1-12 months), toddler (1-5 years), school age (6-12 years), and young adult (12-16 years).

Populations of 10,000 ventricular models per age group were generated using mRNA expression data and then calibrated against cellular electrophysiological biomarkers and corrected QT (QTc) clinical data. The final calibrated populations contain 300 models per age group.

    Note: The scripts in this repository assume that the initial populations of models and the 3D simulation outputs already exist.

Repository structure
  
    ---simulate_pop_by_age.m              # Run control or drug simulations for each age-specific population
    ---biomarkers_control_all_ages.m      # Compute AP biomarkers from control simulations
    ---biomarkers_w_drugs_allages.m       # Compute AP biomarkers from drug simulations (40 drugs × 3 concentrations)
    ---calibration_0D.m                   # 0D calibration of the 10k models per age using biomarker ranges
    ---calibration_3D.m                   # 3D calibration: QTc-based selection of the final 300 models per age
    ---data_40_drugs.xlsx                 # Drug library: EFTPC, IC50 and Hill coefficients for 7 ion channels
    ---f_aux/                             # Auxiliary functions (biomarker computation, drug state, model main, etc.)
    ---populations/                       # Initial populations of models (pop_<age>.mat) — see Prerequisites
    ------final_300_<age>.csv                # IDs of the final 300 models per age (output of calibration)
    ------SS_final_300_<age>_<bcl>.mat       # Steady-state initial conditions for drug simulations
    ---sim_control_per_age/               # Output folder for control simulation results

Prerequisites

    MATLAB R2024b with the Parallel Computing Toolbox (the scripts use parpool / parfor).

    The initial population files populations/pop_<age>.mat, each containing a matrix poblacion with one row per model (column 1 = model ID, columns 2-end = model parameters/conductances).

    The steady-state file SS_final_300_<age>_<bcl>.mat with a matrix X0 (column 1 = model ID, columns 2-end = state variables), used as initial conditions for drug simulations.

    For the 3D calibration step: pseudo-ECG output files (.dat) generated by the 3D simulation software, plus the clinical QTc reference values from Rijnbeek et al. (2001).

Workflow
1. Generate the initial populations of models
Not included in this repository. 10,000 models per age group were generated using mRNA expression data and the O'Hara-Rudy formulation. The resulting files should be placed in populations/.

2. Run control simulations
Run simulate_pop_by_age.m to simulate each model in the population at a fixed or age-adjusted cycle length (BCL). 
Set drug_list = 0 for control simulations. 
Results are saved in control_sim_<age>_<bcl>/.

3. Compute biomarkers from control simulations
Run biomarkers_control_all_ages.m. This computes AP biomarkers (APD30/40/50/90, triangulation, Vpeak, RMP, dV/dtmax, qnet, CTD50/90, Cai systolic/diastolic, nai, EMw) for each model and saves them to biomarkers_<age>_<bcl>_ini_pop_control.csv.

4. 0D calibration
Run calibration_0D.m. This filters the 10,000 models per age using physiologically plausible ranges for the biomarkers (following Llopis-Lorente et al., 2022). Output: biomarkers_<age>_<bcl>_calibration_0D_control.csv.

5. 3D calibration
The 3D simulations themselves are not included. Run the 3D simulations externally, compute pseudo-ECGs, and use calibration_3D.m to measure QT/QTc and compare against clinical data (Rijnbeek et al., 2001). This step selects the final 300 models per age using a weighted normal sampling over the APD90 range defined in Table 2 of the accompanying manuscript. Output: final_300_<age>.csv.

6. Run drug simulations
Modify simulate_pop_by_age.m to set drug_list = 1:40 and d_list = [1, 5, 10], and provide the steady-state file SS_final_300_<age>_<bcl>.mat. The script will simulate all 300 models × 40 drugs × 3 concentrations for each age group.

7. Compute biomarkers from drug simulations
Run biomarkers_w_drugs_allages.m. This computes the same biomarkers (subset) for every drug/concentration/model combination and saves them to biomarkers_<age>_<bcl>_w_drugs.csv.

8. Analysis
Downstream analysis (repolarization abnormalities, incidence quantification, figures) is performed on the biomarker tables.

Data files
- data_40_drugs.xlsx --> Drug library with EFTPC, IC50 and Hill coefficients for hERG (IKr), INa, INaL, ICaL, IKs, IK1, and Ito. 40 drugs across classes H (high risk), I (intermediate), L (low risk).
- final_300_<age>.csv --> IDs of the 300 models selected after 3D calibration for each age group.
- SS_final_300_<age>_<bcl>.mat --> Steady-state state variables for each of the 300 models, used as initial conditions for drug simulations.
- biomarkers_<age>_<bcl>_ini_pop_control.csv --> Biomarkers for the full 10,000-model control population.
- biomarkers_<age>_<bcl>_calibration_0D_control.csv --> Biomarkers for models passing the 0D calibration.
- biomarkers_<age>_<bcl>_w_drugs.csv --> Biomarkers for all drug simulations.
